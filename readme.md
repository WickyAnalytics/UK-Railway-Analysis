## 🔍 Project Highlights
### Key Objectives:
✔ Clean and preprocess 31K+ railway records  
✔ Design normalized database 
✔ Develop interactive Tableau/Power BI dashboards  
✔ Implement forecasting models using Prophet  



### Major Findings:
- Identified peak travel hours (6-8 AM, 4-8 PM)
- Determined top delay causes (weather, staffing, signals)
- Analyzed revenue trends ($741K total, 5% refund rate)
- Forecasted May bookings with 8.27% MAPE accuracy
